# تدقيق إدارة المستخدمين لصاحب المدرسة

## الحالة الحالية

نُفذت إدارة الحسابات الآمنة في تغيير مستقل بترحيل `0052_school_user_accounts.sql`. تفاصيل بوابة التفعيل والنشر في [تقرير الإصدار](SCHOOL_USER_ACCOUNTS_RELEASE.md)؛ اكتمال التنفيذ المحلي وحده لا يعني اكتمال النشر.

| الوظيفة | التنفيذ | الحماية |
|---|---|---|
| عرض مستخدمي المدرسة | واجهة/API لمدير النظام ومالك المدرسة | المدرسة مثبتة من جلسة المالك |
| إنشاء حساب | المالك ينشئ المدير ونائبه والمدرس والمحاسب والمسجل وولي الأمر | منع الأدوار المحمية والمدارس الأخرى؛ كلمة مؤقتة مولدة من الخادم |
| تعديل الحساب والدور | حفظ ذري يتطلب `expected_revision` | لا نقل بين المدارس، ولا تعديل النفس أو الحسابات المحمية؛ رفض النسخة القديمة بـ`409 account_stale` |
| تفعيل/تعطيل الحساب | تحديث الحالة وإبطال الجلسات | إلغاء روابط الوصول عند تغيير الحالة؛ إعادة التفعيل لا تعيد الروابط تلقائيًا |
| إعادة تعيين كلمة المرور | كلمة عشوائية صالحة 24 ساعة تظهر بعد العملية فقط | تغيير إلزامي قبل دخول الصفحات الخاصة/API والطباعة؛ لا تخزين في المتصفح أو سجل التدقيق |

## القيود الأمنية المنفذة

1. يثبت الخادم مدرسة `school_owner` من جلسة المصادقة، ولا يثق بقيمة `school_id` المرسلة من الواجهة.
2. لا يستطيع `school_owner` إنشاء أو تعيين الدورين `system_admin` و`school_owner`.
3. كل قراءة أو تعديل أو تفعيل أو إعادة تعيين يجب أن يرفض المستخدم التابع لمدرسة أخرى.
4. لا تُعاد كلمة المرور القديمة أو تجزئتها في أي استجابة. تقتصر استجابة التفاصيل على حقول آمنة.
5. الإنشاء وإعادة التعيين يفرضان `must_change_password`. التغيير يتطلب الكلمة الحالية وأخرى مختلفة من 12 إلى 128 حرفًا، ويبطل كل الجلسات. صيغة التجزئة وتوقيع الجلسة المؤقتتين يمنعان النسخة القديمة من قبولها أثناء الانتقال.
6. تسجل عمليات الإنشاء والتعديل وتغيير الحالة وإعادة التعيين والتغيير الذاتي في سجل غير قابل للتعديل أو الحذف، دون كلمات مرور أو تجزئات أو رموز جلسات. يعيد الحفظ الذري فحص صلاحية الجلسة والدور والمدرسة والنسخة داخل D1.

## الروابط والترحيل

إنشاء حساب لا يمنح المدرس أو ولي الأمر وصولًا تلقائيًا إلى موظف أو طالب. تظل روابط الوصول الحالية مطلوبة. يدعم API إنشاء حساب مدرس مع رابط موظف صالح في دفعة ذرية، وتوفر واجهة روابط الوصول إدارة الربط المعتادة. تغيير الدور يلغي الروابط القائمة.

يضيف الترحيل ثلاثة أعمدة افتراضية للمستخدمين وجدولي التدقيق والحراسة، ويتيح إلغاء رابط حساب معطل دون إضعاف شروط التفعيل أو تغيير هوية الرابط. لا يعيد كتابة الجداول الدراسية أو الدرجات أو المالية. تسبق نشر التطبيق نسخة خاصة واستعادة مطابقة وبروفة ترحيل وفحص STAGING مصادق، كما يحدد تقرير الإصدار.
