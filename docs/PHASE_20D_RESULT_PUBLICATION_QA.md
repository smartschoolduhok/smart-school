تضيف هذه الدفعة دورة رسمية تفصل بين إنشاء كارت النتيجة ونشره. الكارت الجديد يبدأ مسودة لا تظهر لولي الأمر ولا تعمل في صفحة التحقق العامة. بعد مراجعة الإدارة يمكن نشره صراحةً، وعند وجود خطأ يُسحب بسبب إلزامي مع حفظ سجل تدقيق غير قابل للتغيير.

الدفعة لا تغيّر حسابات الدرجات أو سياسة النجاح والإكمال والإعفاء والدخول الوزاري التي ثبتتها Phase 20C، ولا تربط النتيجة آليًا بترحيل الطالب بعد. الربط مع الترحيل يبقى Phase 20D.2 بعد قبول دورة النشر.

## عقد النشر

| الحالة | الظهور لولي الأمر | التحقق العام | الطباعة الرسمية | الانتقال المسموح |
|---|---|---|---|---|
| `draft` | مخفي | 404 / غير منشور | ممنوعة | نشر أو إلغاء المسودة |
| `published` | ظاهر للابن المرتبط فقط | صالح | مسموحة | سحب موثق فقط |
| `withdrawn` | مخفي فورًا | غير صالح/مسحوب | ممنوعة | حالة نهائية محفوظة تاريخيًا |

شروط النشر:

- المستخدم من أدوار إدارة النتائج.
- المدرسة المستهدفة فعالة ومطابقة للسجل.
- `expected_revision` يطابق النسخة الحالية لمنع طلب متزامن أو قديم.
- الكارت كامل وليس جزئيًا.
- snapshot الكارت مرتبط بسياسة سنوية حالتها `approved` أو `locked`.
- السياسة تحتوي مرجع قرار غير فارغ.

السحب يتطلب سببًا من 1 إلى 1000 حرف. إلغاء الكارت المباشر يبقى لمسودة فعالة فقط، ولا يمكن استخدامه لتجاوز سجل سحب النتيجة المنشورة.

## وصول ولي الأمر والخصوصية

المسار `GET /api/parent/students/:id/result-cards` يعيد فقط النتائج المنشورة والفعالة لطالب فعال مرتبط بالمستخدم عبر `parent_student_links` فعال وفي المدرسة نفسها. تعطيل الرابط أو سحب النتيجة يوقف الوصول فورًا.

الاستجابة تستخدم قائمة حقول مسموحة صريحة. لا ترسل:

- `verification_hash`.
- هوية منشئ الكارت أو منفذ قرار الدرجات.
- IDs داخلية للمواد أو سجلات القرار.
- ملاحظات لجنة داخلية أو سجل التدقيق.
- snapshot الكامل أو أعمدة لا تحتاجها واجهة ولي الأمر.

تظهر في ملف الطالب: السنة والصف والشعبة والنتيجة الأكاديمية والدخول الوزاري والإعفاء والدور، ثم المواد والدرجة المصدر ودرجات القرار والدرجة المعدلة والحالة، مع رابط التحقق العام. المسودات والنتائج المسحوبة لا تظهر.
