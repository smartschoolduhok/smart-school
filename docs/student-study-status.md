# صفة الدراسة واستثناء العمر وإظهار الدرجات

هذه الإضافة تحفظ وضع الطالب **لكل مدرسة وسنة دراسية**: منتظم، استضافة، أو انتساب، مع خيار مستقل لإظهار درجاته. الطالب يبقى في دليل الطلاب والقيد السنوي وقوائم التوزيع عند إخفاء درجاته. لا تُغيّر هذه الإضافة شروط الوزارة أو تعتمد مصدرًا رسميًا بدل المدرسة.

## الاستخدام

1. افتح ملف الطالب، ثم «الوضع الدراسي السنوي»، واختر السنة.
2. اختر منتظم / استضافة / انتساب. اختيار الصفة وحده لا يُخفي الدرجات.
3. حدد إظهار الدرجات أو إخفاءها، ودوّن سبب التعديل، ثم احفظ.
4. إذا كان للطالب كتاب استثناء عمر، فعّل الاستثناء وأدخل مرجعه وتاريخه والجهة المصدرة والسبب والصف المقصود. يؤكد مسؤول الإدارة أنه راجع الكتاب ونطاق السنة والصف قبل توثيقه.
5. من صفحة الطلاب افتح طباعة قوائم الطلاب، واختر السنة والصف والشعبة ومرشح الصفة المطلوب. عمود «صفة الدراسة» يميز طلبة الاستضافة والانتساب. لا تتضمن ورقة التوزيع الدرجات أو مرجع الاستثناء أو تفاصيله.

المالك والمدير والمعاون يستطيعون تعديل هذه الإعدادات، والمسجل يستطيع مراجعتها وطباعة القوائم. لا تُعرض تفاصيل كتب الاستثناء للمدرس أو ولي الأمر. تظل صلاحيات الصفوف والطلبة والمدرسة الأخرى خاضعة للتحقق المعتاد.

## العمر والقبول والاستمرار

- فحص أعمار الطلاب المستمرين تنبيه للمراجعة؛ لا يحذف الطالب أو يوقف قيده تلقائيًا.
- الاستثناء الموثق يعالج تجاوز **الحد العددي للعمر فقط**، سواء الأصغر أو الأكبر إذا نصت اللائحة على ذلك الحد. لا يتجاوز تاريخ ميلاد مستحيل أو مستقبلي أو مفقود، ولا يحل محل لائحة غائبة أو مستندات القبول أو شروط الإعادة والتسريع.
- لا يخترع النظام حدًا أدنى للعمر من كتاب يحدد أقدم مواليد فقط. صغر العمر وحده ليس دليل تسريع أو استثناء.
- يحفظ الاستثناء السنة والصف وتاريخ الميلاد والجنس عند توثيقه. تغيير هذه البيانات لا ينقل الاستثناء تلقائيًا إلى نطاق جديد؛ تظهر الحاجة إلى مراجعته وإعادة توثيقه.
- يمكن حفظ الإعداد لطالب له هوية مسجلة قبل إنشاء القيد السنوي. لمتقدم جديد لديه استثناء: سجّل هوية الطالب بلا صف أولًا، وثق استثناء السنة والصف، ثم استخدم هذه الهوية في طلب القبول.
- تغيير سجل الاستثناء يبطل معاينة القبول واعتماده المعلق عند التنفيذ، ويلزم إعادة المراجعة؛ لا تنفذ موافقة قديمة بناءً على استثناء أُلغي أو تغيّر.

## معنى إخفاء الدرجات

يُحجب عرض الدرجات وتعديلها وتقاريرها ونتائجها وتصديرها للسنة المحددة، وتبقى القيم الأصلية محفوظة. يمكن للإدارة إعادة إظهارها من الإعداد نفسه. لا تصبح الدرجة صفرًا أو غيابًا بسبب الإخفاء، ولا يُحذف الطالب من قوائم التوزيع أو الحضور أو الرسوم.

الدرجات الحية في البنية الحالية لا تحمل سنة مستقلة؛ لذلك تستعمل سنة المدرسة الفعالة. كروت النتائج وتقارير المتابعة المحفوظة تستعمل السنة المحفوظة في كل سجل. لا ينقل النظام اختيار الاستضافة أو الانتساب أو إخفاء الدرجات تلقائيًا إلى السنة التالية.

القوائم المطبوعة تعتمد القيود السنوية النشطة للطلبة النشطين في السنة المختارة؛ المرشح يحدد قائمة التوزيع المطلوبة. يبقى الطالب ذو الدرجات المخفية ضمن القائمة وتظهر صفته.

## البيانات والتحقق

الترحيل `0055_student_study_status.sql` يضيف جدول الإعدادات السنوية وجدول سجل تغييراتها فقط. السجل القديم غير المعدل يعامل كمنتظم ودرجاته ظاهرة، دون تعبئة تلقائية أو تغيير بيانات الطلاب والدرجات والرسوم. كل تعديل يتحقق من المدرسة والصلاحية والإصدار ويحفظ سجلًا لا يُعدل ولا يُحذف.

التحقق يشمل اختبارات سلوك الواجهات، عزل المدارس والسنوات، الاستثناء بعد تغيير الهوية، عدم تجاوز الشروط الأخرى، حجب مسارات الدرجات والتصدير والنتائج، وبقاء الطلبة في قوائم الطباعة. `npm run test:student-study-status:local` يختبر الترحيل على D1 محلي حقيقي ببيانات مصطنعة، ويحفظ دليل تطابق الجداول القديمة والتراجع الكامل إذا فشلت كتابة سجل التدقيق.

هذه ميزة لتنظيم الحالات الموثقة؛ لا تعني اعتماد لوائح المنار لعام 2026–2027 أو إجراء تجربة مدرسية فعلية أو نشر التعديل على بيئة التشغيل.
