# كتاب الأوامر المدرسية للمدرسين

يظهر قالب «الأوامر المدرسية للمدرسين» ضمن الكتب الرسمية لكل مدرسة. يحمل الكتاب ترويسة المدرسة المختارة وشعارها وتذييلها، ويحمّل كادرها الفعّال فقط، مع المعاون في البداية. للمدرسين عنوان «مدرس» افتراضيًا؛ يمكن تعديل أي عنوان في القائمة.

يمكن إضافة أسماء يدويًا، وتعديل الأسماء والعناوين الوظيفية، وحذف الصفوف وترتيبها، أو إعادة تحميل كادر المدرسة. تحدد المدرسة العدد والتاريخ والجهة المخاطبة والنص. الطباعة تدعم كتابًا مع قائمة في مرفق مستقل، أو القائمة وحدها. يتكرر رأس الجدول وتبقى الصفوف متصلة عند امتداده إلى صفحات أخرى.

يحفظ الإصدار قائمة الكادر والترويسة والشعار ومصدر النص داخل snapshot الكتاب؛ لا يغير سجل الموظف. زر «إنشاء نسخة معدلة» يستعيد القائمة ومصدر النص للتحرير، ويطلب عددًا جديدًا للإصدار، مع بقاء الكتاب السابق ثابتًا. تبديل المدرسة يمسح مسودة المدرسة السابقة. API الكادر الخاص بالكتب يكشف بيانات الأسماء والعناوين المحدودة فقط، ويرفض ربط موظف من مدرسة أخرى.

شعار المنار محفوظ في `public/manar-school-logo.png` من أصل الشعار المتاح في صفحة تطبيق مجموعة مدارس المنار في App Store. يُربط بإعداد مدرسة المنار وحدها؛ المكوّن لا يحتوي أسماء مدارس أو شعارات ثابتة.

التحقق يشمل اختبارات API وعزل المدارس، تحرير القائمة والنسخ والتبديل في الواجهة، ومعاينة مباشرة دون زيارة الطباعة أولًا. فحص Chromium أكد صفحة واحدة لقائمة ٢٢ اسمًا، وصفحتين للكتاب مع هذه القائمة، وأربع صفحات لقائمة ١٠٠ اسم مع تكرار العناوين. يضم `test:official-books` اختبارات العرض الجديدة أيضًا.
